# Portfólio Juliana Barros

Site pessoal e portfólio de Juliana Barros, desenvolvido com React e Vite para apresentar sua atuação como desenvolvedora de materiais paradidáticos, além de divulgar informações sobre sua trajetória e experiência profissional.

## Visão geral

Este projeto foi criado para funcionar como uma landing page institucional, com navegação entre páginas dedicadas a:

- Paradidático
- Sobre
- Experiência profissional

A interface utiliza uma estética visual moderna, com imagens, cards e layout voltado para apresentação pessoal e profissional.

## Tecnologias utilizadas

- React
- Vite
- React Router DOM
- CSS personalizado
- JavaScript

## Estrutura do projeto

```bash
src/
```

## Funcionalidades

- Página inicial com apresentação principal
- Navegação entre seções do portfólio
- Layout visual com foco em identidade pessoal
- Exibição de materiais paradidáticos e experiências
- Estrutura preparada para expansão do conteúdo

## Pré-requisitos

Antes de iniciar, certifique-se de ter instalado:

- Node.js (versão 18 ou superior)
- npm

## Instalação

```bash
npm install
```

## Executando o projeto

Para rodar o projeto em modo de desenvolvimento:

```bash
npm run dev
```

Depois, abra o endereço informado no terminal, normalmente:

```bash
http://localhost:5173
```

## Build de produção

Para gerar a versão otimizada para produção:

```bash
npm run build
```

## Preview da build

```bash
npm run preview
```

## Observações

Este repositório é um projeto front-end voltado para portfólio pessoal e pode ser adaptado facilmente para incluir novos textos, imagens, links e páginas.
